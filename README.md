# World Archive v0.99x

가상 세계 지도·연표·세계관 통합 편집기입니다.

## 핵심 변경

- 래스터 분석 + 벡터 지형 경계 하이브리드 렌더링
- 동적인 해안선·호수 경계
- 실제 km 면적에 연동되는 지형 패치 크기
- 도시·강·지류 기반 농경지 후처리
- 시드 아래 접이식 고급 지도 설정
- 지도 중심 위도 설정 통합

## VS Code 실행

```bash
npm install
npm run dev
```

검사: `npm run typecheck`, `npm run smoke`, `npm run worker:smoke`
