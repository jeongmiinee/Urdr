World Archive v0.99x - Windows 11 x64 무설치판

1. ZIP 파일을 원하는 폴더에 완전히 압축 해제합니다.
2. 압축 해제한 폴더에서 `World Archive.exe`를 실행합니다.
3. `World Archive.exe`와 `web` 폴더는 반드시 같은 위치에 두십시오.
4. Windows에 설치된 Microsoft Edge 또는 Google Chrome을 앱 모드로 사용합니다.
5. 첫 실행에서 SmartScreen이 표시되면 파일 출처를 확인한 뒤 실행 여부를 직접 선택하십시오.

재실행 문제 대응
- 프로그램 창을 닫은 직후 다시 EXE를 실행하면 기존 백그라운드 인스턴스에 활성화 요청을 보내 창을 복원합니다.
- 창이 계속 나타나지 않으면 작업 관리자에서 `World Archive`와 관련 Edge/Chrome 앱 모드를 종료한 뒤 `안전 모드로 실행.cmd`를 사용하십시오.
- 콘솔 로그가 필요하면 `World Archive - Console.exe`를 실행하십시오.

데이터는 브라우저 로컬 저장소를 사용하므로 중요한 프로젝트는 프로그램의 내보내기 기능으로 별도 백업하십시오.
